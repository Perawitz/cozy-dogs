# Cozy Dogs 🐶 v7.2 — 2D Cozy Multiplayer (โครงงานเน็ตเวิร์ค)

เกมเลี้ยงสุนัขแนวคอซี่ มีบ้านพิกเซลอาร์ตแบบละเอียด สุนัข 50 สายพันธุ์ + พรีเมียม 11 สายพันธุ์ ตกแต่งบ้านได้ เล่นกับเพื่อนแบบออนไลน์ ฟักไข่ ผสมพันธุ์ ประกวดหมา คุยด้วยเสียงในสวน

## วิธีรัน
```
node server.js        # หรือ npm start  -> เปิด http://localhost:3000
```
ไม่ต้อง `npm install` — ถ้ามีแพ็กเกจ `ws` จะใช้ตัวนั้น ถ้าไม่มีจะใช้ `miniws.js` (WebSocket server ที่เขียนเอง ไม่พึ่ง library)
ต้องใช้ Node 18+ (ทดสอบบน Node 22) · เล่นหลายเครื่องในวง LAN: `http://<IP เครื่อง server>:3000`

- แก้บั๊ก: **หลังคาบ้านนอกหน้าต่างกลับหัว** (วาดสามเหลี่ยมชี้ลง) → ชี้ขึ้นแล้วและมีปล่องควัน · กันหน้าจอล็อกอินเด้ง error ในเสี้ยววินาทีแรก (เลขเฟรมอนิเมชันติดลบ)

## ใหม่ใน v7.1 — 📣 ประกาศถึงทุกคน (ซื้อด้วยเพชร)

ผู้เล่นพิมพ์ข้อความสั้น ๆ เลือกสไตล์ แล้วจ่ายเพชร ข้อความจะเด้งเป็นแบนเนอร์น่ารัก ๆ บนหน้าจอของ **ผู้เล่นออนไลน์ทุกคน** (ปุ่ม 📣 ในแถบเมนูล่าง)

| สไตล์ | ราคา | แสดงนาน | หน้าตา |
|---|---|---|---|
| 💗 หัวใจ | 3 เพชร | 7 วิ | ชมพูอ่อน มีหัวใจลอยขึ้น |
| ⭐ ดาวทอง | 8 เพชร | 9 วิ | สีทอง ดาววิบวับ |
| 🌈 สายรุ้ง | 20 เพชร | 12 วิ | กรอบสีรุ้งวิ่ง คอนเฟตตีร่วง มีเสียงแฟนแฟร์ |

กติกา (เซิร์ฟเวอร์เป็นผู้ตัดสินทั้งหมด ไฟล์ `announce.js`):
- เฉพาะสมาชิก (Guest ประกาศไม่ได้) · ข้อความ 1–60 **ตัวอักษร** (ตัดตามตัวอักษร ไม่ตัดกลางอีโมจิ) · ห้ามลิงก์ · กรองคำหยาบพื้นฐาน
- แบนเนอร์ **ไม่ซ้อนกัน**: ประกาศเข้าคิวเดียวกัน (รอได้สูงสุด 6) ถ้าคิวเต็มจะไม่หักเพชร · คูลดาวน์ 30 วิต่อคน
- หักเพชรเมื่อประกาศ "ผ่านเข้าคิว" เท่านั้น (ข้อความที่ถูกปฏิเสธไม่เสียเพชร) · คิวและประกาศ 20 อันล่าสุดเก็บใน `db.ann` ประกาศที่จ่ายแล้วจึงไม่หายถ้าเซิร์ฟเวอร์รีสตาร์ท
- คนที่เพิ่งเข้าเกมตอนแบนเนอร์กำลังแสดง จะเห็นส่วนที่เหลือของมัน · แท็บ "ประกาศล่าสุด" ดูย้อนหลังได้ · ผู้เล่นปิดการแสดงได้ที่ ⚙️ ตั้งค่า → "แสดงประกาศ" (หรือกด ✕ บนแบนเนอร์)
- ตัวแปรสำหรับสาธิต/ทดสอบ: `CD_ANN_SCALE=10` (แบนเนอร์สั้นลง 10 เท่า) · `CD_ANN_CD=0` (ไม่มีคูลดาวน์)
- ทดสอบ: `server_test15.js` (36 ข้อ: ราคา/คิว/ไม่ซ้อนกัน/ไม่เสียเพชรเมื่อถูกปฏิเสธ/ลิงก์/คำหยาบ/ข้อความประหลาด/ท่วมด้วยข้อความ/รีสตาร์ท) · `browser_tests/announce.py` (หน้าต่าง พรีวิวสด แบนเนอร์ 3 แบบ บนจอคอม/มือถือแนวตั้ง/แนวนอน)

## ใหม่ใน v7 — ไข่ · หมาโตตามวัย · ผสมพันธุ์ · ร้านหมา/ตลาด · ประกวดหมา · แชทส่วนตัว · ไมค์ในสวน
(ทำตามโจทย์ 10 ข้อที่อาจารย์แนะนำ — ข้อ 3 กับข้อ 5 ซ้ำกัน ("ช่องแชทส่วนตัวไว้คุยกับเพื่อน") จึงรวมเป็นระบบเดียว)

| # | ที่อาจารย์ขอ | อยู่ตรงไหนในเกม |
|---|---|---|
| 1 | แพ้เกมแข่งแล้วโดนหักเงิน | เกมออนไลน์ทุกเกม + เป่ายิ้งฉุบ — ดู "ค่าแพ้" ด้านล่าง |

| 3, 5 | แชทส่วนตัวคุยกับเพื่อน | ปุ่ม 💌 บนแถบล่าง: แชทสองคน + ห้องแชทกลุ่มเฉพาะเพื่อน |
| 4 | ปิดบ้านไม่ให้คนมาเยี่ยมได้ | หน้า 🏡 บ้าน → "ความเป็นส่วนตัวของบ้าน" |
| 6 | เปิดไมค์ในสวนสาธารณะ | ปุ่มไมค์ 🎤 ในสวน (เสียงส่งตรงระหว่างผู้เล่น WebRTC) |
| 7 | ผสมพันธุ์ · พันธุ์แท้/พันทาง · ลักษณะใหม่ ๆ น่ารัก ๆ | ปุ่ม 🧬 ผสมพันธุ์ + ลักษณะพิเศษ 17 แบบ |
| 8 | ประกวดหมาให้คนในเซิร์ฟเวอร์ตัดสิน ทุกชั่วโมง มีเงินรางวัล | ปุ่ม 👑 ประกวดหมา |
| 9 | กาชาเปลี่ยนเป็นสุ่มไข่ | ปุ่ม 🥚 สุ่มไข่ (ไข่สั่น → แตก → ลูกหมาเบบี๋) |
| 10 | ซื้อ-ขายหมา · หมาน่ารัก/หายากซื้อได้ด้วยเพชรหรือทองเท่านั้น | ปุ่ม 🐾 ร้านหมา (ชั้นพรีเมียม · ขายให้ร้าน · ตลาดผู้เล่น) |

("ทอง" ในเกม = เหรียญ 💰 · "เพชร" = 💎)

### 1) แพ้แล้วโดนหักเหรียญ
- ฝั่งที่แพ้ **ไม่ได้รางวัลและโดนหัก**: เกม 2 คน คนแพ้ −20 · เกม 3 คน คนสุดท้าย −25 · เกม 4 คน อันดับ 3 −15 และอันดับ 4 −30 · เป่ายิ้งฉุบ แพ้ −15 (เสมอไม่หัก)
- เล่นกับบอทอย่างเดียว **หักครึ่งเดียว** · ออกกลางเกมที่กำลังเล่น = นับว่าแพ้ (−20)
- กันไม่ให้ผู้เล่นใหม่จนเกินไป: ถ้ามีเหรียญ **ไม่ถึง 30 จะไม่ถูกหัก** · หักรวมไม่เกิน **400 เหรียญต่อวัน**
- ผลเกมขึ้นกล่องแดง "−X เหรียญ ค่าแพ้" และหน้าเกมเตือนไว้ตั้งแต่ก่อนเริ่ม

### 2) หมาโตตามวัย + ลูกอมโตเร็ว
- นับจากวันเกิด: **เบบี๋ < 6 ชม. · ลูกหมา < 24 ชม. · วัยรุ่น < 72 ชม. · หลังจากนั้นโตเต็มวัย** (ตัวเล็กลงตามวัย: เล็กสุดคือเบบี๋) · หมาเก่าที่มีอยู่ก่อนอัปเดตถือว่าโตเต็มวัยแล้ว
- 🍬 **ลูกอมโตเร็ว** (ร้านค้า → อาหาร 90 เหรียญ): โตเร็วขึ้นเทียบเท่า 6 ชม. · ให้ได้ไม่เกิน 6 เม็ด/วัน/ตัว · หมาโตเต็มวัยแล้วกินไม่ได้
- ผสมพันธุ์ได้เฉพาะหมา **โตเต็มวัย** · ขายให้ร้านได้ราคาน้อยลงถ้ายังเด็ก

### 3) สุ่มไข่ 🥚
- ราคา/โอกาสความหายากเท่าเดิม (100 เหรียญต่อไข่ · การันตีตำนานทุก 40 ครั้ง) แต่ได้ **ไข่** ที่สั่นแล้วแตก ออกมาเป็น **ลูกหมาเบบี๋** · ประมาณ 1 ใน 12 ฟองได้ **ลักษณะพิเศษ**
- กดรัว ๆ ได้ (ผลทยอยแสดงทีละหน้า) · กดที่หน้าจอเพื่อข้ามแอนิเมชัน

### 4) ผสมพันธุ์ 🧬 · พันธุ์แท้ / พันทาง / ลักษณะพิเศษ
- เลือกหมา 2 ตัว (โตเต็มวัย ไม่ได้พักอยู่ ไม่ใช่พรีเมียม) → จ่ายค่าผสม (ตามความหายากของพ่อแม่ตัวที่หายากกว่า: ธรรมดา 80 · หายาก 150 · เอพิค 300 · ตำนาน 600 · มิสติก 1000) → ได้ **ไข่** วางในรัง (จำนวนช่อง = 2 + ระดับบ้าน) → รอฟัก (30 นาที – 6 ชม. ตามความหายาก **ลดลงได้สูงสุด 25% ถ้าพ่อแม่สนิทกับเจ้าของมาก**) · เร่งด้วยเพชร 1💎 / 15 นาที (สูงสุด 24💎) · พ่อแม่พัก 12 ชม.
- **พันธุ์แท้**: ยีนสองข้างเป็นสายพันธุ์เดียวกัน · **พันทาง (ลูกผสม)**: ยีนสองข้างต่างสายพันธุ์ — ชื่อ "A × B" สีและรูปร่างผสมกัน ลูกหมาแต่ละตัวหน้าตาไม่ซ้ำ (มีเมล็ดสุ่มรูปลักษณ์) · พ่อแม่ให้ยีนคนละข้าง ยีนที่หายากกว่ามีโอกาสเป็นหน้าตาเด่นมากกว่า
- **กลายพันธุ์ 4%**: ยีนหนึ่งเปลี่ยนเป็นสายพันธุ์ที่ **หายากกว่าหนึ่งขั้น** (ขึ้นข้อความพิเศษตอนฟัก)
- **ลักษณะพิเศษ (17 แบบ ✨)**: สืบทอดจากพ่อแม่ 50% ต่อลักษณะ · โอกาสได้ลักษณะใหม่ 12% (พันธุ์แท้) / 30% (พันทาง) บวกเพิ่มถ้าพ่อแม่สนิทมาก · สูงสุด 2 อย่างต่อตัว · แต่ละอย่างมีโบนัสเล็ก ๆ และมีเอฟเฟกต์ลอยรอบตัวสำหรับระดับ ⭐⭐ ขึ้นไป
  - ระดับธรรมดา: 🍑 แก้มแดงระเรื่อ · 🍪 ลายกระจุ๋มจิ๋ม · 🌙 รอยพระจันทร์ · ☁️ ปุยเมฆ · 🦝 หน้ากากโจรจิ๋ว · 😛 แลบลิ้นเล่น
  - ระดับน่ารัก: 💗 รอยหัวใจ · ⭐ รอยดาว · 🌱 ต้นอ่อนบนหัว · 🌼 ดอกไม้ข้างหู · 💭 ฟองสบู่ลอย · 🐝 หนวดผึ้งน้อย
  - ระดับหายาก: 😇 วงแหวนนางฟ้า · 🕊️ ปีกจิ๋ว · ✨ ขนประกายระยิบ · 🌈 สายรุ้งบนหลัง · ❄️ หมาน้ำแข็ง
  - โบนัส: Bond เพิ่มเวลาดูแล · รางวัลคำขอ (wish) · XP ดูแล · ค่าต่าง ๆ ลดช้าลง · ขุดเหรียญเพิ่ม · ขายได้แพงขึ้น · เสน่ห์ตอนประกวด
- หน้าผสมพันธุ์โชว์ตัวอย่างโอกาส (พันธุ์แท้/พันทาง/กลายพันธุ์/ลักษณะ) ก่อนกดยืนยัน — เทสต์ยืนยันแล้วว่าตัวเลขที่โชว์ตรงกับที่เซิร์ฟเวอร์สุ่มจริง (สุ่มทดสอบ 30,000 รอบต่อคู่)

### 5) ร้านหมา 🐾 · ตลาดผู้เล่น · หมาพรีเมียม
- **ชั้นพรีเมียม (สต็อกจำกัดต่อวัน รีเซ็ตเที่ยงคืนเวลาไทย · ไม่อยู่ในไข่ ผสมพันธุ์ไม่ได้ · ไม่นับในสมุดสะสม 50 ตัว แต่มีหมวด "หมาพรีเมียม" แยก)**
  - ซื้อด้วยเหรียญ: 🍡 Mochi Pup 1,800 · 🧸 Teddy Pom 2,400 · 🐰 Bunny Corgi 3,200 · 🐼 Panda Pup 4,500
  - ซื้อด้วยเพชร: 🌸 Sakura Shiba 45 · 🍭 Cotton Candy Poodle 70 · 🍓 Strawberry Dalmatian 60 · 🐝 Honey Bee Pup 90 · 😇 Angel Retriever 120 · 🦄 Unicorn Pup 180 · 🐉 Dragon Pup 260
- **ข้อเสนอวันนี้**: สายพันธุ์ธรรมดา 5 ตัวลดราคาตามความหายาก (150 / 420 / 1,000 / 2,600 เหรียญ · สีพิเศษแพงขึ้น 1.4 เท่า) · ซื้อได้คนละไม่เกิน 8 ครั้ง/วัน
- **ขายให้ร้าน**: ราคา = ฐานตามความหายาก × วัย (เบบี๋ 35% → โตเต็มวัย 100%) × Bond × พันทาง × ลักษณะ · ห้ามขายตัวโปรด ตัวที่อยู่นอกบ้าน หรือตัวสุดท้ายของบ้าน
- **ตลาดผู้เล่น**: เลเวล 3+ · ลงขายได้ 5 รายการ · ตั้งราคาเป็นเหรียญ (50–99,999) หรือเพชร (1–9,999) · ค่าธรรมเนียม 5% · หมดเวลา 48 ชม. หมากลับบ้านพร้อมจดหมายแจ้ง · ผู้ขายได้เงินทางจดหมาย (กด "รับ") · ซื้อพร้อมกัน 2 คน = ได้แค่คนแรก

### 6) ประกวดหมา 👑 (ทุกชั่วโมง)
- วงจร 1 ชม.: **0–42% รับสมัคร** (ส่งหมา 1 ตัว) → **42–88% โหวต** (ทุกคนมี 3 คะแนน โหวตซ้ำ = ยกเลิก โหวตให้ตัวเองไม่ได้ ต้องเลเวล 2+ และไม่ใช่ Guest) → **88–100% ประกาศผล**
- ซ่อนคะแนนโหวตจนกว่าจะประกาศผล · คะแนนรวม = โหวต × 3 + "เสน่ห์" (Bond · ลักษณะพิเศษ · ความหายาก · พันทาง · โตเต็มวัย · มีเครื่องประดับ) ทำให้เซิร์ฟเวอร์เงียบ ๆ ก็ยังตัดสินได้ยุติธรรม
- รางวัล (ต้องมีผู้เข้าประกวด 3+ ตัว ไม่งั้นยกเลิกรอบ): 🥇 400💰+3💎 · 🥈 250💰+1💎 · 🥉 150💰 · คนอื่น 20💰 — ส่งทางจดหมาย (ออฟไลน์ก็ได้รับ) · โหวตครั้งแรกของรอบได้ +10💰
- แชมป์ได้ **มงกุฎ 👑 24 ชม.** (เห็นข้างชื่อหมาที่บ้านและในสวน) และเข้าหอเกียรติยศ (20 รอบล่าสุด)

### 7) บ้านส่วนตัว 🔒
- ตั้งได้ 3 แบบ: 🔓 เปิดรับทุกคน · 👥 เฉพาะเพื่อน · 🔒 ปิดบ้าน — **เซิร์ฟเวอร์ตรวจทุกครั้งที่มีคนขอเข้า** (ส่งข้อความเลี่ยงไม่ได้) · ตอนปรับให้เข้มขึ้นแขกที่อยู่ในบ้านจะถูกส่งกลับบ้านตัวเองทันที (ลบเพื่อนก็เช่นกัน) · รายชื่อผู้เล่นออนไลน์/เพื่อนมีไอคอน 🔒

### 8) แชทส่วนตัว 💌 (ข้อ 3 และ 5)
- แชทสองคนกับ **เพื่อนที่เป็นเพื่อนกันทั้งสองฝั่ง** + ห้องแชทกลุ่มเฉพาะเพื่อน (สูงสุด 8 คน ชื่อห้องไม่เกิน 16 ตัวอักษร) · สมาชิกใหม่ไม่เห็นข้อความก่อนที่เข้าห้อง · ปิดเสียงห้อง · เก็บข้อความล่าสุด 100 ข้อความ/ห้อง (ล้างห้องที่เงียบเกิน 60 วัน) · มีตัวเลขข้อความที่ยังไม่อ่านบนปุ่ม 💌 และข้อความเด้งเตือน
- ปุ่ม 💬 ข้างชื่อเพื่อนในหน้า "เพื่อน" เปิดห้องคุยได้เลย

### 9) ไมค์ในสวนสาธารณะ 🎤
- ในสวนกดปุ่มไมค์เพื่อเข้า **ช่องเสียงของสวน** (ต้องกดเข้าเอง ไม่มีใครถูกเปิดไมค์โดยอัตโนมัติ) · มีไอคอนบอกว่าใครกำลังพูด · **ยิ่งอยู่ไกลกันในสวนเสียงยิ่งเบา** (proximity chat — ปิดได้) · ปิดไมค์ตัวเอง และปรับเสียง/ปิดเสียงรายคนได้ · ช่องรับได้ 8 คน
- ครั้งแรกจะเตือนก่อนว่า **ผู้ร่วมช่องเห็น IP กันและกัน** (ข้อจำกัดของการส่งตรงระหว่างผู้เล่น)

## ตั้งค่า (ตัวแปรแวดล้อม — ไม่ตั้งก็ใช้ค่าปกติ)
| ตัวแปร | ความหมาย |
|---|---|
| `CD_GROW=3600` | เร่งเวลาโตของหมา (1 = เวลาจริง · 3600 = โตเต็มวัยใน ~1 นาที) — ไว้สาธิต/ทดสอบ |
| `CD_HATCH=600` | เร่งเวลาฟักไข่และพักของพ่อแม่ (600 = ไข่ 1 ชม. ฟักใน 6 วินาที) |
| `CD_SHOW_MS=60000` | ความยาวของรอบประกวด (ค่าปกติ 3,600,000 = 1 ชม.) — ตั้ง 60000 เพื่อสาธิตให้อาจารย์ดูรอบละ 1 นาที |
| `TURN_URL` `TURN_USER` `TURN_PASS` | เซิร์ฟเวอร์ TURN สำหรับไมค์ในสวน (ไม่ตั้ง = ใช้ STUN ของ Google อย่างเดียว — ผู้เล่นหลังเราเตอร์บางแบบ/เน็ตมือถือบางเจ้าอาจเชื่อมไม่ได้) · `TURN_SECRET` = โหมดรหัสชั่วคราว (coturn `use-auth-secret`) · `CD_ICE` = รายการ ICE server เองเป็น JSON (แทนที่ค่าเริ่มต้น) |

### เบื้องหลังเครือข่ายของ v7 (ไว้อธิบายอาจารย์)
- **เซิร์ฟเวอร์เป็นผู้ตัดสิน (server-authoritative)**: เวลาโตของหมา เวลาฟักไข่ การสุ่มยีน ราคา สต็อก การโหวต และค่าแพ้ คำนวณที่เซิร์ฟเวอร์ทั้งหมด ไคลเอนต์ส่งแค่ "คำขอ" เช่น `nur_pair` `pet_buy` `sh_vote` แล้วเซิร์ฟเวอร์ตรวจใหม่ทุกครั้ง (ข้อมูลที่ส่งมาเป็น JSON อะไรก็ได้) · มีเทสต์ยิงข้อมูลขยะ/ตัวเลขใหญ่เกิน/`__proto__` ใส่ทุกข้อความ
- **การซิงค์เวลา**: หมาโตตามเวลาจริง ฝั่งไคลเอนต์วาดตามอายุเอง จึงต้องรู้นาฬิกาของเซิร์ฟเวอร์ — ข้อความ `welcome` ส่งเวลาเซิร์ฟเวอร์ (`v7.t0`) มา ไคลเอนต์เก็บส่วนต่าง `S.skew` ไว้ ทำให้นาฬิกาเครื่องเพี้ยนก็ไม่ทำให้หมาโตผิดเวลา (ใช้หลักเดียวกับ NTP แบบง่าย ๆ)
- **ข้อความใหม่ (client→server)**: `nur_get nur_pair nur_hatch nur_fast` (ผสมพันธุ์) · `pet_shop pet_buy pet_sell` (ร้านหมา) · `mk_get mk_put mk_buy mk_cancel` (ตลาด) · `sh_get sh_enter sh_unenter sh_vote` (ประกวด) · `set_priv` (ความเป็นส่วนตัว) · `dm_*` (แชทส่วนตัว) · `voice_*` (ไมค์) — **(server→client)**: `nur` `nur_ok` `nur_hatched` `pet_shop` `pet_stock` `pet_bought` `pet_sold` `mk` `sh` `sh_ph` `dm_*` `voice_*` ฯลฯ
- **ตลาด = ธุรกรรมที่ต้องไม่ซ้ำ**: เซิร์ฟเวอร์เป็น single-threaded จึงเรียงลำดับคำขอให้เอง "ซื้อพร้อมกัน 2 คน" คนที่ 2 จะพบว่ารายการหายไปแล้ว (มีเทสต์ race) · ย้ายหมาออกจากผู้ขายตอนลงขาย (กันขายซ้ำ/เอาไปแลกต่อ) · หมดเวลาแล้วคืนเจ้าของ
- **ไมค์ในสวน (WebRTC)**: เสียงไม่ผ่านเซิร์ฟเวอร์ — ผู้เล่นต่อกันเอง (peer-to-peer แบบ full mesh) ใช้ WebSocket ของเกมเป็น **ช่องสัญญาณ (signalling)** ส่งต่อ `offer/answer` (SDP) ระหว่างสองคนในช่องเท่านั้น · NAT ทะลุด้วย **ICE**: STUN บอกที่อยู่สาธารณะ ถ้า NAT เข้มต้องใช้ **TURN** ช่วยรีเลย์ · เสียงเข้ารหัส DTLS-SRTP · คนที่เพิ่งเข้าช่องเป็นฝ่ายส่ง offer เสมอ (กัน "glare" ที่สองฝั่งส่งพร้อมกันแล้วค้าง) · full mesh คุมที่ 8 คน (28 เส้น ≈ 224 kbit/s อัปโหลดต่อคน) ถ้ามากกว่านี้ต้องใช้ SFU
- ข้อมูลทั้งหมดของ v7 อยู่ในฐานข้อมูลเดิม (`data.json` / Supabase): หมามีฟิลด์ใหม่ `mix ms tr born rest crown` · ผู้เล่นมี `nest priv sb` · ส่วนกลางมี `db.market db.show db.shop db.chats` — **บัญชีเดิมเปิดได้ต่อเลย** (หมาเก่าถือว่าโตเต็มวัย)

### 1) ล็อกอินด้วยบัญชี Google (Gmail)
- มีปุ่ม **Sign in with Google** ใต้ฟอร์มที่หน้าเข้าสู่ระบบ (แท็บ "สมัครสมาชิก" ก็มี) — กดแล้วเลือกบัญชี Google ในหน้าต่างเล็ก เสร็จแล้วเข้าเกมเลย
- **ผู้เล่นใหม่**: หลังเลือกบัญชีจะมีหน้าต่าง "ตั้งชื่อในเกม" (เดาชื่อให้จากอีเมล แก้ได้) — ชื่อซ้ำ/ผิดรูปแบบจะแจ้งในหน้าต่างเดิมและยังไม่สร้างบัญชี
- **คนที่มีบัญชีรหัสผ่านอยู่แล้ว**: ตั้งค่า → 🔗 Google → ปุ่มผูกบัญชี — ผูกแล้วเข้าได้ทั้งสองทาง ข้อมูลเกมเดิมอยู่ครบ
- บัญชีที่สมัครด้วย Google ไม่มีรหัสผ่านและไม่มีรหัสกู้คืน (Google คือทางกลับเข้าบัญชี) · Guest ผูกไม่ได้
- **ตั้งค่าครั้งเดียวก่อนปุ่มจะโผล่** (ถ้ายังไม่ตั้ง เกมทำงานเหมือนเดิมทุกอย่าง แค่ไม่มีปุ่ม Google):
  1. เข้า https://console.cloud.google.com/ ด้วยบัญชี Google ของคุณ → สร้างโปรเจกต์ใหม่ (ชื่ออะไรก็ได้ เช่น `cozy-dogs`)
  2. เมนู **APIs & Services → OAuth consent screen** (หรือ **Google Auth Platform**) → เลือก **External** · ชื่อแอป `Cozy Dogs` · ใส่อีเมลติดต่อ → บันทึก (ไม่ต้องเพิ่ม scope เอง ใช้ค่าพื้นฐาน openid / email / profile)
  3. กด **Publish app** (ให้สถานะเป็น "In production") — ถ้าค้างที่ "Testing" จะมีแค่อีเมลที่เพิ่มเป็น Test user เท่านั้นที่ล็อกอินได้ (อาจารย์จะเข้าไม่ได้) · scope พื้นฐานไม่ต้องรอ Google ตรวจแอป
  4. เมนู **Credentials → Create credentials → OAuth client ID** → ประเภท **Web application** → ช่อง **Authorized JavaScript origins** กด Add URI ใส่ `https://cozy-dogs.onrender.com` (ถ้าจะลองในเครื่องให้เพิ่ม `http://localhost` และ `http://localhost:3000` ด้วย) → Create → คัดลอก **Client ID** (หน้าตาเช่น `1234567890-abcdefg.apps.googleusercontent.com`) — ไม่ต้องใช้ Client secret และไม่ต้องใส่ Redirect URI
  5. ที่ Render → เซอร์วิสของเกม → **Environment** → Add `GOOGLE_CLIENT_ID` = Client ID ที่คัดลอก → Save (Render จะ deploy ใหม่เอง) · ถ้ารันในเครื่อง: Windows CMD พิมพ์ `set GOOGLE_CLIENT_ID=ใส่ไอดี` แล้วค่อย `node server.js` (PowerShell: `$env:GOOGLE_CLIENT_ID="ใส่ไอดี"`)
  6. เปิดเกมใหม่ → เห็นปุ่ม Google ใต้ฟอร์มล็อกอิน · ถ้าปุ่มขึ้นข้อความว่า origin ไม่ได้รับอนุญาต (*origin is not allowed*) แปลว่า URL ใน Authorized JavaScript origins ไม่ตรงกับที่เปิดอยู่ (ต้องตรงทั้ง https / พอร์ต / ไม่มี `/` ท้าย) หรือรอสักพักให้ Google อัปเดต (5 นาที – ไม่กี่ชั่วโมง)
- **ความปลอดภัย** (ไว้อธิบายอาจารย์): เบราว์เซอร์ได้ "ID token" (JWT) จาก Google แล้วส่งให้เซิร์ฟเวอร์ → **เซิร์ฟเวอร์ตรวจเอง** ด้วย `node:crypto` (ไม่ต้องลงไลบรารี): ลายเซ็น RS256 กับกุญแจสาธารณะของ Google (ดึงจาก `googleapis.com/oauth2/v3/certs` แล้วแคชตาม `Cache-Control`), ผู้ออก `iss`, ผู้รับ `aud` ต้องเป็น Client ID ของเรา, วันหมดอายุ, `email_verified` — ไม่เชื่อสิ่งที่เบราว์เซอร์อ้างมาเองเลย · บัญชีผูกกับ **รหัสผู้ใช้ Google (`sub`)** ไม่ใช่อีเมล (อีเมลที่พิมพ์ตอนสมัครด้วยรหัสผ่านไม่ได้ยืนยัน จึงห้ามใช้ตัดสินว่าเป็นคนเดียวกัน) · ลองผิดนับรวมในขีดจำกัดต่อ IP เหมือนล็อกอินปกติ
- **ข้อจำกัดที่ควรรู้**: เบราว์เซอร์ในแอป (Instagram / Facebook / LINE) มักบล็อกหน้าต่างล็อกอินของ Google → เกมจะขึ้นข้อความแนะนำให้เปิดด้วย Safari/Chrome · การทดสอบอัตโนมัติใช้ "Google ปลอม" ในเครื่อง (เซ็นโทเคนด้วยกุญแจของเราเอง ผ่านโค้ดตรวจของเซิร์ฟเวอร์ตัวจริงทั้งหมด) เพราะเรียก Google ตัวจริงจากชุดทดสอบไม่ได้ — ควรลองกดปุ่มจริงหลังตั้งค่า Client ID เสร็จ

### 2) ป้าย Achievement เหนือหัวตัวละคร
- ภารกิจ → แท็บ **🏆 ความสำเร็จ** → ทุกอันที่ทำสำเร็จแล้วจะมีปุ่ม **"แสดงเหนือหัว"** — เลือกได้ **1 อัน** (เลือกอันใหม่ = แทนที่ · กดอันเดิมซ้ำ = ซ่อน)
- เป็นป้ายทองเล็ก ๆ "🏆 ชื่อ Achievement" เหนือหัวตัวละคร — เห็นทั้งที่บ้านตัวเอง ตอนเพื่อนมาเยี่ยมบ้าน และในสวนสาธารณะ (คนอื่นเห็นทันทีที่เปลี่ยน) · ป้ายหลบให้ฟองคำพูดเวลามีคนพูด
- เซิร์ฟเวอร์ตรวจเอง: เลือกได้เฉพาะอันที่สำเร็จจริง (ส่งไอดีปลอมไม่ได้) · อันแบบ "ถือเหรียญ 2000" ถ้าเหรียญตกต่ำกว่านั้นป้ายจะซ่อนเอง แล้วกลับมาเมื่อทำได้อีก · จำไว้ข้ามการล็อกอิน

### 3) จำกัดการลูบหัวต่อวัน
- ปุ่ม **ลูบ (Pet)** มีตัวนับ เช่น `37/100` (ครั้งที่นับผลวันนี้) — รีเซ็ตเที่ยงคืนเวลาไทย
- ครบแล้ว: การลูบไม่เพิ่มความสนิท / ความสุข / XP / เควสต์ / ความคืบหน้า Achievement จนถึงพรุ่งนี้ (หมายังมีหัวใจลอยให้เล็กน้อย) และแจ้งเตือน 1 ครั้ง (ไม่ขึ้นรัวทุกครั้งที่กด) · ลูบเพื่อทำตามคำขอ (wish) ของหมายังทำได้ · ลูบหมาของเพื่อนที่มาเยี่ยม = ได้หัวใจเฉย ๆ ไม่นับ
- ปรับจำนวนได้ด้วยตัวแปรแวดล้อม `CD_PET_DAILY` (ค่าเริ่มต้น 100)

**🖥️ เซิร์ฟเวอร์**
- **บน Render ผู้เล่นทุกคนถูกนับเป็น IP เดียว** (ขีดจำกัด 25 ครั้ง/5 นาที, สมัคร 10 ครั้ง/ชม., Guest 40 ครั้ง/ชม. กลายเป็นของทั้งเว็บ — เพื่อนในห้องเข้าพร้อมกันก็เต็ม) → อ่าน IP ผู้เล่นจาก `X-Forwarded-For` (Render ตั้งให้อัตโนมัติ; ตัวแปร `TRUST_PROXY_HOPS` ปรับได้ 0 = ปิด) · นับเฉพาะ "การลองที่ผิด" (ล็อกอินสำเร็จไม่กินโควต้า) · ผู้ที่แอบอ้างเป็น 127.0.0.1 ก็ยังโดนจำกัด

## ใหม่ใน v6.1 — หมากัดกัน (Dog Brawl) + เป่ายิ้งฉุบออนไลน์ + แก้บั๊กรอบใหญ่
**⚔️ หมากัดกัน (Dog Brawl)** — เกมออนไลน์ใหม่ 2–4 คน สู้กัน 6 รอบแบบ "ทุกคนเลือกท่าลับพร้อมกัน" แล้วเซิร์ฟเวอร์ตัดสินผลทีเดียว · เลือกน้องหมาที่จะลงสนามเองได้ (ดูค่าพลังและสกิลก่อนกด "หาคู่ต่อสู้") · ถ้าไม่มีผู้เล่นจริงจะมีบอทมาสู้ด้วย (รางวัลลดครึ่ง)
- **ค่าพลังไม่เหมือนกัน**: HP · ATK (โจมตี) · DEF (ป้องกัน) · SPD (ความเร็ว: ใครลงมือก่อน / โอกาสหลบ / คริติคอล) คำนวณจาก "ความหายาก + ขนาดตัว + สไตล์การสู้" (นักสู้ ⚔️ / ตัวถึก 🛡️ / สายเร็ว 💨 / สายแสบ 🎩) — 50 สายพันธุ์ได้ชุดค่าไม่ซ้ำกันอย่างน้อย 40 แบบ
- **สกิลประจำตัว**: ทุกสายพันธุ์มี 2 สกิลจาก 13 สกิล (กัดรัว · ทุบกระดูก · ตีหางหมุน · กระโจนเร็ว · เห่าขู่ · ขโมยกระดูก · หอนก้องฟ้า · ขนฟูกันกระแทก · งีบเอาแรง · วิ่งซิ่งหลบ · ตาแป๋ว · ขนมวิเศษ · โหมดบ้าพลัง) ใช้พลังงาน ⚡ (ได้คืน +1 ทุกรอบ, ท่า "ป้องกัน" ได้เพิ่มอีก +1) นอกจากนี้ทุกตัวมีท่าพื้นฐาน "กัด" และ "ป้องกัน"
- **ใครชนะ**: ตัวสุดท้ายที่ยังยืนอยู่ — ถ้าครบ 6 รอบแล้วยังเหลือหลายตัว ตัดสินด้วย HP ที่เหลือ แล้วค่อยดูดาเมจรวม · คนที่ไม่เลือกท่าภายใน 7 วินาทีจะกัดอัตโนมัติ
- **หน้าจอ**: เลือกนักสู้ → ล็อบบี้ → สนามประลองบน Canvas (เลขดาเมจ/คริติคอล/หลบ/โล่/ฟื้น HP/สถานะ, แตะศัตรูเพื่อเลือกเป้า) · ใช้ได้ทั้งมือถือแนวตั้ง-แนวนอนและคอม · มีหน้ากติกาและรายการสกิล
**✊ เป่ายิ้งฉุบ = เกมออนไลน์** — ย้ายขึ้นไปอยู่ในหมวด "เกมออนไลน์" ของหน้าเกม (ไม่ใช่มินิเกมเล่นคนเดียวแล้ว) · ถ้าไม่มีผู้เล่นจริงเข้ามาภายใน ~8 วินาที บอทจะมาเล่นด้วย (ได้รางวัลครึ่งเดียว และนับในโควต้าเหรียญเกมออนไลน์ 600/วัน)
**🛋️ ลบเฟอร์นิเจอร์ได้แล้ว** — ในโหมดตกแต่ง แตะชิ้นที่ต้องการแล้วมีปุ่มลอย 🔄 พลิก · 📦 เก็บเข้ากระเป๋า · 🗑 ลบทิ้ง (แตะ 2 ครั้งเพื่อยืนยัน) · กด Delete/Backspace บนคีย์บอร์ดเพื่อเก็บเข้ากระเป๋า · ลากไอเทมจากลิ้นชักไปวางในห้องได้จริง (เดิมลากแล้วไม่วาง)
**🐞 บั๊กที่แก้**
- **อันดับในเกมออนไลน์ผิด (กระทบทุกเกม)** — ฟังก์ชันจัดอันดับส่ง "ลำดับที่" แทนที่จะส่ง "ตัวผู้เล่น" ให้ตัวคำนวณ ทำให้ทุกเกมจัดอันดับตามลำดับเข้าห้อง: คนที่เข้ามาทีหลังแต่เข้าเส้นชัยก่อน (หรือคะแนนสูงกว่า) ได้ที่ 2 และรางวัลน้อยกว่า
- **แชทบนมือถือพิมพ์ไม่ได้** — เดิมซ่อนกล่องแชทไว้ทั้งหมดบนหน้าจอโทรศัพท์ ตอนนี้เป็นปุ่ม "💬 แชท" กดแล้วพิมพ์ได้ (ช่องพิมพ์ 16px กัน iOS ซูม) และข้อความที่เข้ามาระหว่างพิมพ์ไม่ทำให้ข้อความที่พิมพ์ค้างอยู่หาย/คีย์บอร์ดปิดอีก
- **กดสุ่มไข่กาชารัว ๆ แล้วปุ่ม OK กดไม่ได้** — หน้าผลลัพธ์ซ้อนกันหลายชั้น ตอนนี้ล็อกปุ่มสุ่มระหว่างรอผล ถ้ามีหลายผลจะโชว์ทีละหน้า (ปุ่มบอก "OK · ยังมีอีก N") และกด Enter/Space/Esc ปิดได้

### เบื้องหลังเครือข่ายของ v6.1 (ไว้อธิบายอาจารย์)
- **โปรโตคอลแบบเลือกท่าพร้อมกัน (simultaneous turns)**: แต่ละรอบมี 2 เฟส — `mp_ba` (เซิร์ฟเวอร์ส่งสถานะ HP/พลังงาน/สถานะพิเศษ + เวลาตอบ 7 วินาที) → ผู้เล่นส่ง `mp_bp {r, a, to}` ซึ่ง **ซ่อนอยู่ที่เซิร์ฟเวอร์** ไม่มีใครเห็นท่าของคนอื่น → ครบทุกคนหรือหมดเวลา เซิร์ฟเวอร์ resolve แล้ว broadcast `mp_bx` (ลิสต์เหตุการณ์ hit/miss/heal/ko…) ให้ client เล่นอนิเมชันตามลำดับ · เลขรอบ `r` กันแพ็กเก็ตเก่า/ซ้ำ · ท่าที่ผิดกติกา (พลังงานไม่พอ/เป้าหมายล้มแล้ว) เซิร์ฟเวอร์ปฏิเสธด้วย `mp_bno` และให้เลือกใหม่ · ใช้ท่าแรกที่ส่งมาเท่านั้น
- **กติกาแยกเป็นฟังก์ชันบริสุทธิ์**: `brawl.js` (ไม่มี socket/ไม่มีนาฬิกา) + ข้อมูลกลาง `brawl_data.js` ที่ฝังลง `public/index.html` ด้วยตอน build → ค่าพลัง/สกิลฝั่ง client และ server ตรงกันเสมอ และจำลองแมตช์จำนวนมากเพื่อจูนบาลานซ์ได้ (`brawl_test.js`)
- **ตัดการเชื่อมต่อกลางแมตช์**: หมาของคนที่หลุดถือว่าสลบ ถ้าเหลือตัวเดียวแมตช์จบทันที ไม่ต้องรอหมดเวลา
- **ตัวแปรสำหรับเทสต์เท่านั้น**: `CD_BRFAST=4` เร่งบอท/จังหวะพักระหว่างรอบ เพื่อให้ชุดทดสอบจบเร็ว (ปล่อยว่างตอนใช้งานจริง)
- **ทดสอบ** (`npm test` รันให้ทั้งหมด): `server_test6.js` (หมากัดกัน + เป่ายิ้งฉุบบอท) · `server_test7.js` (อันดับถูกต้องในทุกเกมออนไลน์เมื่อคนที่เข้าทีหลังเก่งกว่า) · `brawl_test.js` (กติกา/บาลานซ์) · `fuzz_test.js` (ยิงท่าขยะใส่ระหว่างแมตช์จริง) · ส่วนหน้าจอ (แชทมือถือ, ลบเฟอร์, กาชารัว, เป่ายิ้งฉุบ, หมากัดกัน, Dog Race) ทดสอบด้วยเบราว์เซอร์จริง 3 ขนาดจอ — สคริปต์อยู่ใน `browser_tests/` (Python + Playwright, ดูวิธีรันในไฟล์ README ของโฟลเดอร์นั้น)

**🏠 อยู่ในบ้าน** — ตัวคนยืนที่ **มุมใดมุมหนึ่งของห้อง** (เลือกได้ 4 มุม: หลังซ้าย/หลังขวา/หน้าซ้าย/หน้าขวา) · แตะเพื่อให้โบกมือ · น้องหมาที่กำลัง "ตามหาเจ้าของ" จะเดินมาหาข้าง ๆ คนและคนทำท่าดีใจ · แชทของเจ้าของเด้งเป็นฟองเหนือหัว · เวลาไปเยี่ยมบ้านเพื่อนก็เห็นตัวคนของเขาในมุมของเขา
**🌳 ไปสวนสาธารณะ = คนจูงหมา** — กด 🌳 แล้วตัวคนเดินจูงน้องหมาด้วยสายจูงสีที่เลือก (สายเสียบที่มือคน → ปลอกคอหมา) คนเดินตามหลังหมาเสมอ สลับข้างเองเมื่อหมาเปลี่ยนทิศ · ลุยน้ำในบ่อได้ (น้ำกระเพื่อม) · ทำท่าตามอีโมจิ (👋 โบกมือ) · ผู้เล่นคนอื่นเห็นชุดของเราในสวนทันที · แตะที่ตัวคนก็เปิดการ์ดผู้เล่นได้
**🧸 ส่วนอื่นที่ละเอียดขึ้น** — การ์ดผู้เล่นมุมซ้ายบน · หน้าโปรไฟล์ผู้เล่น · การ์ดผู้เล่นในสวน มีรูปคนคู่กับหมา · รูปคนในรายชื่อเพื่อน/อันดับ · หน้าว่างแบบน่ารัก · ฝุ่นพิกเซลตอนวิ่งในสวน · ภารกิจใหม่ 1 ข้อ + Achievement ใหม่ 5 อัน (รวม 38) · แปลชื่อไอเทม/อาหาร/สายพันธุ์/นิสัย/ลูกเล่นเป็นไทยทั้งหมด · แก้ UI ที่ยังไม่น่ารัก (ลิงก์ดิบ ๆ, ปุ่มซ้อนกับห้อง, ป้ายข้อความทับกัน) · เพิ่มเทสต์ฝั่งเซิร์ฟเวอร์ 61 ข้อสำหรับตู้เสื้อผ้า + fuzz

### เบื้องหลังเครือข่ายของ v6 (ไว้อธิบายอาจารย์)
- **Server-authoritative wardrobe**: client ส่งแค่ "ลุคที่อยากได้" (`av_save`, ~250 ไบต์) เซิร์ฟเวอร์เป็นคนตรวจทุกฟิลด์กับแคตตาล็อกกลาง `avatar_data.js` (ใช้ไฟล์เดียวกันทั้ง server และ client → ราคา/กติกาตรงกันเสมอ) ค่าที่ไม่รู้จัก/นอกช่วง/ชนิดผิดจะถูกทิ้งกลับเป็นค่าเดิม ราคาคิดจากรายการ `avOwn` ที่เซิร์ฟเวอร์เก็บเอง ไม่เชื่อราคาจาก client
- **Atomic purchase**: เช็คเหรียญก่อน ถ้าไม่พอ → `av_err{code:'coins'}` ไม่หักอะไรเลย ไม่มีกรณีซื้อครึ่งเดียว · ซื้อชิ้นที่มีอยู่แล้วไม่หักซ้ำ · throttle 350 ms ต่อ socket กันกดรัว
- **Fan-out แบบ interest management**: เปลี่ยนลุคแล้วเซิร์ฟเวอร์ส่ง `av_upd` เฉพาะคนที่กำลังดูบ้านนั้น (`toView`) และ `park_av` เฉพาะคนในสวน · คนที่เข้ามาทีหลังได้ลุคมาพร้อม snapshot (`house` / `park_init` / `park_in`) จึงไม่ต้อง polling
- **คนเดินจูงหมา = คำนวณฝั่ง client ล้วน ๆ**: ตำแหน่งคนคือ "ตามหลังหมา" (smoothing + hysteresis เลือกข้าง) จากตำแหน่งหมาที่เซิร์ฟเวอร์ส่งอยู่แล้ว (`park_s` 10 Hz) จึง **ไม่เพิ่มแบนด์วิดท์เลย** และตำแหน่งคนถูก clamp อยู่ในขอบเขตสนามเสมอ (อ้างอิงจากหมาที่เซิร์ฟเวอร์คุมอยู่)
- **ซ่อมข้อมูลตอนสตาร์ท**: `ensure()` ตรวจ `data.json` ทุกบัญชี — ลุคพัง/ค่าแปลก/ชิ้นพรีเมียมที่ไม่ได้ซื้อ → กลับเป็นชิ้นฟรี, `avOwn` เหลือเฉพาะคีย์จริงไม่ซ้ำ (ทดสอบด้วยการแก้ไฟล์ข้อมูลมือแล้วรีสตาร์ท)
- **ทดสอบ**: `server_test5.js` (61 ข้อ: ตรวจลุค, ซื้อ/ไม่พอเหรียญ, bundle แบบ atomic, payload อันตราย `__proto__`/`constructor`/ตัวเลขนอกช่วง/สตริงยาว/เฟรมเกิน 4KB, flood, กระจายลุคถึงผู้มาเยี่ยมและคนในสวน, Achievement, ซ่อมข้อมูลหลังรีสตาร์ท) + `fuzz_test.js` ยิง `av_save`/`av_get` แบบสุ่ม

## ใหม่ใน v5 — น้องหมามีบทบาท เกมออนไลน์เพียบ และเป้าหมายระยะยาว
**💭 คำขอของน้องหมา (Wishes)** — น้องหมาขอของตามนิสัย (ลูบหัว/เล่น/หวีขน/อาบน้ำ/ฝึก/อาหารที่ชอบ) ฟองคำขอลอยเหนือหัว ทำครบรับเหรียญ+โบนัส (หมดอายุใน 15 นาที, ค้างได้สูงสุด 2 คำขอ)
**🎾 โยนบอล (Fetch)** — กดปุ่ม 🎾 แล้วแตะพื้น น้องหมาวิ่งไปคาบบอลกลับมา · **⛏️ ขุดสมบัติ** ในสวน (มีสมบัติกลางที่ทุกคนช่วยกันหา พร้อมคำใบ้ ร้อน/อุ่น/เย็น) · **🥏 จานร่อน** สุ่มตกในสวน ใครวิ่งไปรับก่อนได้เหรียญ
**🌐 เกมออนไลน์เรียลไทม์ 5 เกม** (เซิร์ฟเวอร์เป็นผู้ตัดสินทั้งหมด · ผู้เล่นจริงก่อน ถ้าไม่มีใครจะมีบอทเติมให้ — รางวัลลดครึ่ง · เหรียญสูงสุด 600/วัน)
- 🏁 **Dog Race** 2–4 คน แตะซ้าย-ขวาสลับกัน (กันสแปมด้วยการจำกัดความถี่ + ต้องสลับข้าง) · 🦴 **Bone Grab** 1v1 วัดปฏิกิริยา ชดเชย latency ด้วย RTT ที่วัดจริง · 🍪 **Treat Frenzy** ขนมโผล่กลางจอ ใครแตะก่อนได้ (race condition ตัดสินที่เซิร์ฟเวอร์) · 🔍 **Odd Pup Out** หาตัวที่แตกต่างในตะแกรง ผิดโดนหักแต้ม+ล็อกชั่วคราว · 🧠 **Breed Duel** ตอบคำถาม 5 ข้อ ตอบไวได้แต้มเพิ่ม (เซิร์ฟเวอร์ไม่ส่งเฉลยก่อนหมดเวลา)

**🎉 สังคม** — ปาร์ตี้ที่บ้าน (เชิญเพื่อนอัตโนมัติ แขกได้เหรียญ) · สมุดเยี่ยม + ❤️ ถูกใจ · ประกวดบ้านประจำสัปดาห์ (3 อันดับแรกได้รางวัลทางจดหมาย) · 📬 กล่องจดหมายสำหรับคนที่ไม่ได้ออนไลน์ (ของขวัญ/ไลก์/สมุดเยี่ยม/รางวัล)
**อื่น ๆ** — 🎰 วงล้อนำโชค (ฟรีวันละครั้ง) · 🌱 ภารกิจมือใหม่ 10 ข้อ + บทแนะนำเริ่มเกม · Achievement รวม 33 อัน · ตารางอันดับเพิ่ม 4 แท็บ (อาร์เคด/ถูกใจ/อบอุ่น/คำขอ)

### เบื้องหลังเครือข่ายของ v5 (ไว้อธิบายอาจารย์)
- **Room-based matchmaking + bot fill**: ล็อบบี้ต่อเกม รอ ~8 วินาทีหรือจนเต็ม (เริ่มทันทีเมื่อเต็ม) · ถ้ามีคนเดียวเติมบอทให้ จึงไม่มีใครติดรอ · ตัดการเชื่อมต่อกลางเกม = ออกจากห้อง (Bone Grab = แพ้, เกมอื่นเล่นต่อได้)
- **Server-authoritative ทุกเกม**: client ส่งแค่ "อินพุต" (`mp_tap`, `mp_act`, `mp_hit`, `mp_pick`, `mp_ans`) เซิร์ฟเวอร์ตรวจเวลา/ลำดับ/ความถี่ แล้ว broadcast ผล · เฉลยคำตอบไม่ถูกส่งก่อน reveal
- **Latency compensation**: เซิร์ฟเวอร์ส่ง `mp_p` 3 ครั้งตอนเริ่มห้อง client ตอบ `mp_pr` → วัด RTT ต่ำสุดของแต่ละคน แล้วหักออกจากเวลาปฏิกิริยา (Bone Grab / Odd Pup Out / Breed Duel) เพื่อความยุติธรรม
- **Tick แยกตามเกม**: Race 10 Hz snapshot (client interpolate + predict) · Treat Frenzy ใช้ event (`mp_rs` เกิดขนม / `mp_rx` ถูกแย่ง/หมดอายุ) · เกมคำถามใช้ state machine (count → ask → reveal)
- **Anti-abuse**: daily cap เหรียญ · จำกัดอัตราแตะ · ล็อกหลังเลือกผิด · เวลาตอบต่ำสุด · ตรวจ `own()`/`scrub()` กัน prototype pollution · fuzz test ส่งเฟรม/JSON พังใส่เซิร์ฟเวอร์ · rate-limit ต่อ IP (login/register/guest)
- **Mailbox (store-and-forward)**: เหตุการณ์ที่เกิดตอนเจ้าของไม่ออนไลน์ถูกเก็บเป็นจดหมาย (สูงสุด 30) แล้วส่งให้ตอนล็อกอิน · **Heartbeat** ทุก 20 วินาที ตัดการเชื่อมต่อที่เงียบเกิน 180 วินาที · บันทึกไฟล์แบบ atomic (เขียน tmp แล้ว rename) + สำรอง `.bak`

## ใหม่ใน v4 — ออนไลน์เต็มรูปแบบ
**🌳 สวนหมา (Park)** — แมพกลางที่ผู้เล่นทุกคนพาหมามาเดินเล่นพร้อมกัน (สูงสุด 40 คน)
- แตะพื้นเพื่อเดิน (หรือกด W/A/S/D, ลูกศร) · ปุ่ม 🏃 วิ่ง · อีโมจิ 8 แบบ · ท่านั่ง/นอน/เห่า · ใช้ลูกเล่นที่หมาเรียนรู้แล้ว (หมุน กลิ้ง ฯลฯ) ให้คนอื่นเห็น · แชทมีกรอบคำพูดลอยเหนือหัวหมา
- **ขนมสุ่มเกิด** ใครวิ่งไปถึงก่อนได้ (เหรียญ/เพชร จำกัดวันละ 250 เหรียญ) · **ลูกบอลฟิสิกส์ที่ทุกคนเตะร่วมกัน** · บ่อน้ำมีเป็ดว่าย (หมาลุยน้ำได้) · ฉากเปลี่ยนตามเวลา/อากาศ/ฤดูจริง (ใบไม้ร่วง ต.ค. หิมะ ธ.ค. ตะเกียงไฟกลางคืน หิ่งห้อย)
- แตะหมาของผู้เล่นอื่น → การ์ดผู้เล่น (เยี่ยมบ้าน / เพิ่มเพื่อน / แลกของ) · แสดง ping และจำนวนแพ็กเก็ตที่รับ/วินาทีมุมจอ

**🔁 แลกของระหว่างผู้เล่น** — ไอเทม/อาหาร/เครื่องประดับ/เหรียญ/น้องหมา (สูงสุด 3 ตัว) · ทั้งสองฝ่ายต้องกดยืนยัน · ถ้ามีใครแก้ข้อเสนอ การยืนยันถูกรีเซ็ต · เซิร์ฟเวอร์ตรวจแล้วสลับให้พร้อมกัน (atomic) · แลกไม่ได้: ของที่วางในบ้าน/ใส่อยู่ ตัวโปรด หมาตัวสุดท้าย · Guest แลกไม่ได้
**🌍 เป้าหมายร่วมรายสัปดาห์ (Community)** — ทุกวันจันทร์สุ่มโจทย์ใหม่ (ลูบหัวหมา/เก็บขนม/มินิเกม/เยี่ยมบ้าน/กาชา/ให้อาหาร/แลกของ) ทุกคนช่วยกันเติมแถบเดียวกัน ถึง 34% / 67% / 100% รับรางวัล (ต้องช่วยอย่างน้อย 3 ครั้ง) · เป้าหมายปรับตามจำนวนผู้เล่นที่ active · มีอันดับผู้ช่วยสูงสุด
**อื่น ๆ**: เควสใหม่ 2 ข้อ (ไปสวน / เก็บขนม) · Achievement ใหม่ 3 อัน (เตะบอล, นักล่าขนม, พ่อค้า) รวม 22 อัน

### เบื้องหลังเครือข่ายของ v4 (ไว้อธิบายอาจารย์)
- **Park = authoritative real-time simulation**: เซิร์ฟเวอร์รัน tick 10 Hz คำนวณตำแหน่งสุนัขทุกตัวเอง (client ส่งแค่ "จุดหมาย" `park_move`, เซิร์ฟเวอร์ clamp ขอบแมพและจำกัดความเร็ว เดิน 120 / วิ่ง 205 px/s → โกงวาร์ปไม่ได้) พร้อมฟิสิกส์ลูกบอล (แรงเสียดทาน/สะท้อนขอบ) และ spawn/เก็บขนม (ใครแตะก่อนในลำดับ tick ได้)
- **Delta snapshot**: ส่งเฉพาะสมาชิกที่ขยับหรือบอลที่เคลื่อน + full snapshot ทุก 3 วินาทีเพื่อ self-correct · เหตุการณ์ครั้งเดียว (เข้า/ออก/อีโมจิ/ท่า/ขนมหาย) ส่งเป็นข้อความแยก
- **Client-side prediction + dead reckoning**: หมาของเราเดินทันทีที่คลิก (ไม่รอ RTT) ส่วนของคนอื่นเดินต่อไปยังจุดหมายด้วยความเร็วเดียวกับเซิร์ฟเวอร์ แล้วค่อย ๆ blend เข้าหาตำแหน่งจริง (snap ถ้าคลาดเกิน 45/130 px) · ลูกบอลจำลองฟิสิกส์ฝั่ง client ด้วยสูตรเดียวกัน
- **Latency meter**: `ping`/`pong` ทุก 2 วินาที แสดง RTT
- **Trading = 2-phase confirm + version stamp**: ทุกข้อเสนอเพิ่ม `ver`; `trade_ok` ต้องแนบ ver ล่าสุด (กันยืนยันข้อเสนอเก่าจาก race condition) · ตอน commit ตรวจซ้ำทุกอย่างอีกรอบ (ของอาจถูกใช้/วางระหว่างรอ) แล้วย้ายของทั้งสองทิศในครั้งเดียว · ตัดการเชื่อมต่อ = ยกเลิกเทรด · นับสถิติเทรดได้วันละ 5 ครั้ง (กันฟาร์ม)
- **Community goal = shared aggregate state**: ทุก `bump()` ฝั่งเซิร์ฟเวอร์เพิ่มเข้า counter กลาง (จำกัดต่อคน/วัน) · broadcast แบบ throttle ทุก 3 วินาทีแทนการยิงทุกครั้ง

## สถาปัตยกรรมเครือข่าย (เอาไปอธิบายอาจารย์ได้)
- **WebSocket (TCP) + JSON** เชื่อมต่อแบบ full-duplex, client reconnect + resume session อัตโนมัติ
- **Server-authoritative**: AI สุนัข, เหรียญ, กาชา(+Pity), ร้านค้า, การวางของ (ตรวจขอบเขต/จำนวนในคลัง), เควส, Achievement, มินิเกม, ผลเป่ายิ้งฉุบ คำนวณที่ server — client ส่งแค่ "คำขอ"
- **Authentication**: รหัสผ่านเข้ารหัส scrypt + salt, session token เก็บแบบ SHA-256, rate-limit การลองล็อกอิน · ลืมรหัสผ่าน → รหัสกู้คืน (เก็บเป็นแฮช ใช้ได้ครั้งเดียว) (v6.2)
- **Delta / Event sync**: ส่งเฉพาะตอนสุนัขเปลี่ยนพฤติกรรม (state + จุดเริ่ม/จุดหมาย/เวลา) client interpolate เอง
- **Interest management**: simulate/broadcast เฉพาะบ้านที่มีคนดูอยู่ · tick 1 Hz + State Machine
- **Matchmaking queue** (RPS) พร้อม timeout / ตัดการเชื่อมต่อ = แพ้ · ถ้าไม่มีคู่ภายใน ~8 วินาที บอทมาเล่นแทน (v6.1)
- **ความปลอดภัย**: จำกัด 20 msg/s, payload ≤ 4KB, sanitize ชื่อ/แชท (escape ฝั่ง client), kick session ซ้ำ
- **Persistence**: ข้อมูลทั้งหมดอยู่ในหน่วยความจำ บันทึกลง `data.json` ทุก 5 วินาทีเมื่อมีการเปลี่ยนแปลง (เขียนไฟล์ชั่วคราวแล้ว rename + สำรอง `.bak`) และถ้าตั้ง `SUPABASE_URL`/`SUPABASE_KEY` จะอัปโหลดขึ้น Supabase (ตาราง `game_data` 1 แถว) ด้วยเพื่อให้ข้อมูลอยู่รอดตอน redeploy
