# เทสต์หน้าจอด้วยเบราว์เซอร์จริง (Playwright + Chromium)

ชุดนี้ทดสอบสิ่งที่ `npm test` ทดสอบไม่ได้ — คือ "หน้าเกมที่ผู้เล่นเห็นและกดจริง" บนจอ 3 ขนาด (คอม 1280×800 · มือถือแนวตั้ง 390×844 · มือถือแนวนอน 844×390 แบบแตะนิ้ว)
แต่ละสคริปต์เปิดเซิร์ฟเวอร์ชั่วคราวของตัวเอง (ไฟล์ข้อมูลชั่วคราว ไม่แตะ `data.json` จริง) แล้วสั่งเบราว์เซอร์กด/พิมพ์/ลากจริง ๆ จบด้วยบรรทัด `RESULT ผ่าน / ทั้งหมด`

## เตรียมเครื่อง
```
pip install playwright
playwright install chromium
```
(ต้องมี Node 18+ เหมือนตอนรันเกม) — ภาพหน้าจอระหว่างทดสอบถูกเก็บในโฟลเดอร์ชั่วคราว หรือกำหนดเองด้วย `OUT=./shots`
